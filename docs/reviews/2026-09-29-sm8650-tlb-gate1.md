## 2. §6.2.5 参照系实证修订（v4.1 → v4.2）

Gate 0 低成本锚点对照发现：v4.1 锚定的 512 KiB R 值参照 run
`20260927T182613Z` 其 512 KiB 组实为 **2048 ring passes**
（loads=16777216），与锚点协议的 **8 ring passes** 差 256×。R 值近
地板段对训练量敏感（任务书 §3.2 及 cache 战役评审已确立）。

实测（同设备、同画像值窗口、8 环协议）：

| 指标 | 旧参照 [p25,p75] | Gate 0 实测（10 进程） | 结果 |
|---|---|---|---|
| latency | 2.6548 ns（median 参照） | 2.6521 ns（dev 0.104%） | 过（制度匹配的 short-base 参照） |
| R_0x05 | [287.78, 289.35]/1k | 279.07–287.87（+1 离群 308.27），9/10 低于下界 | 系统性不符 |
| R_0x34 | [0.0105, 0.0134]/1k | 0.107–0.244，10/10 越上界约 14× | 系统性不符 |

latency 对照通过反证"制度匹配的参照即可用"；R 值系统性越界（非离群）
裁定旧 R 参照不可用作 8 环锚点的判定阈值——照其执行将使全部块
fail-closed。**修订（用户已批准）**：512 KiB R 值参照换为 Gate 0 run
`20260929T143631Z`（8 环 G0 base seed 42，八项契约全过）；**选择原则
= 制度匹配，非结果通过**；旧 ctrl run 保留 floor/scale 方向性正控角色
（§3.1 的 `0x05`/`0x34` VERIFIED 资格不受影响——方向性验证限 density
型结论，与训练量无关）。任务书 v4.2 §6.2.5 为权威文本。

## 3. Gate 1 正控（任务书 §5.1 顺序）

判据（冻结）：方向与预期一致、跨进程稳定、无恒零；全样本
`time_running==time_enabled`（逐 case 断言通过，下不赘述）。

### ① G1（run `20260929T144937Z`，512 KiB/16 MiB base）

| 事件 | 512 KiB（floor） | 16 MiB（scale） | 裁定 |
|---|---|---|---|
| `0x2d` L2D_TLB_REFILL | 0.153/1k [0.107,0.275] | 32.115/1k [27.7,46.7]（210×） | **QUALIFIED** |
| `0x2f` L2D_TLB | 123.062/1k [114.6,125.3] | 94.590/1k [67.3,171.5] | **SEMANTICS_UNVERIFIED** |

- `0x2d` 与 `0x34` 的 TRM 语义互证：0x34 "counts on any data access
  which causes L2D_TLB_REFILL"——实测两点 `0x2d` 均略高于 `0x34`
  （32.115 vs 32.023；0.153 vs 0.130），差值为微小的指令侧贡献，
  恰是统一 vs 数据侧 refill 的预期关系。
- `0x2f`（§3.1 gloss："由 L1 refill 引起的 L2 TLB 访问"）：L1 refill
  floor→scale 升 3.6×（285.6→1023.7/1k），`0x2f` 反降（123→94.6），
  且 scale 点跨进程分布 [67.3, 171.5] 与 floor [114.6, 125.3] 重
  叠——方向性与稳定性两肢均不满足。注册 `SEMANTICS_UNVERIFIED`；
  **Q2b 降级**：层级辨识仅由 `0x2d`（+G0）承担，无 access 侧交叉验
  证；不续试新事件（有限终点）。

### ② G2（run `20260929T145255Z`）

| 事件 | 512 KiB | 16 MiB | 裁定 |
|---|---|---|---|
| `0x8136` DTLB_STEP | 0.259/1k [0.25,0.29] | 36.714/1k [34.3,37.3]（142×） | **QUALIFIED** |
| `0x8128` DTLB_WALK_PERCYC | 7.568/1k [6.84,8.35] | 958.672/1k [896,982]（127×） | **QUALIFIED** |

派生观察（仅登记，不进结论）：steps/walk = 2.42（floor）→ 1.06

### ③ G4（runs `20260929T145432Z` base、`…T145551Z` -T、`…T150212Z` -T 16MiB）

| 事件 | 证据 | 裁定 |
|---|---|---|
| `0x813a` DTLB_WALK_SMALL | base 四点 small≈total（0.130≈0.130、0.161≈0.163、0.153≈0.156、36.350≈36.360）；floor→scale 280×；-T 16MiB small 0.013≈total 0.013 | **QUALIFIED** |
| `0x8138` DTLB_WALK_LARGE | base 各点 0.000–0.011；-T mixed（2304/3072）0.000–0.002；-T 16MiB（mixed 10/10、anon_huge=14336 KiB）0.000 | **SEMANTICS_UNVERIFIED** |

`0x8138` 裁定过程（辨识链）：2304/3072 KiB -T 点 actual 含 mixed 但
walk 率在地板（0.14–0.22/1k），large≈0 有"事件失效"与"条件无信号"
两个竞争解释——**大页抑制自身 walk**（一个 2 MiB 大页一次 refill 后
常驻）。补 16 MiB × -T 辨识点（配置
`ptr-chase-sm8650-x4-tlb-ctrl-g4-thp-walk`）：actual=mixed 10/10、
87.5% 大页覆盖，总 walk 从 base 的 36.4/1k 崩到 **0.013/1k**
（2800× 削减，余量全部 small）。THP 成功度恰好抹掉了大页自身的
walk 压力——"恒零"仍无法归因于事件失效。按冻结判据（无恒零肢）注
册 `SEMANTICS_UNVERIFIED`：**记录为无信号条件而非故障证据**；
**Q4 大页证据腿降级**：THP 机制解释由 latency + `0x05` + `0x34`（本
run 已示范总 walk 崩塌）+ `0x813a` 承担；不续试新事件（有限终点）。

附带（Phase D 可行性正面信号）：-T 请求在 2304/3072 KiB 达成
mixed、16 MiB 达成 87.5% 大页覆盖；2304/3072 -T 的 latency
7.494/6.331 ns vs base 7.371/8.049 ns（3072 KiB -21%）。

## 4. §5.3 固定开销扫描（run `20260929T145659Z`，24 case 全 ok）

| buffer | 事件 | worst \|a\|/C(N) | 判定 | 读法 |
|---|---|---|---|---|
| 512K | cycles | 0.117 | 含固定开销 | 启动固定成本 ≈55k cycles/窗（≈8 loads），跨 seed 稳定（spread 0.004） |
| 512K | dtlb_walk | inf（C_formal≈0） | 含固定开销 | 冷启动 ≈8 walks/窗（8 环 8.0、64 环 8.9 实测）；地板密度由固定项主导，稳态斜率 ≈0.028/1k |

| 512K | mem_access_rd | 0.033 | negligible | — |
| 16M | cycles | 0.056 | 含固定开销 | 同启动成本，占比随窗口增大摊薄 |
| 16M | dtlb_walk | 0.771 | 含固定开销 | **模型伪影注记**：实测密度 33.2–37.1/1k 非单调，负截距来自线性外推；slope 0.036/1k 与 64/256 环密度一致，8 环密度在同区间 ±6%——保守判"含固定开销"，转折判定用跨长度斜率（§5.3） |
| 16M | l1d_tlb_refill | 0.035 | negligible | — |
| 16M | mem_access_rd | 0.002 | negligible | — |

跨 seed slope_spread：除 512K dtlb_walk（0.43，地板噪声）与 16M
dtlb_walk（0.12）外全部 ≤0.05（只报告不设阈值）。与 P0″ 注册表
`mem_access_rd` 注记（短训练窗口 ~5–6% 固定开销）交叉一致。

**对后续 Phase 的执行含义**：cycles 与 dtlb_walk 的绝对密度报告标注
"含固定开销"；knee/onset 判定在涉及这两事件时以跨长度一致斜率为准；
mem_access_rd、l1d_tlb_refill 按原密度使用。512K 地板段的 walk 绝对
计数（≈8/窗）在解释 near-floor 曲线时须扣除冷启动项。
