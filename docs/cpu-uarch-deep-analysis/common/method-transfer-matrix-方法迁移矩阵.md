## 二、分部件启动清单（从矩阵派生，v0.2 按评审4 重写 ROB/Cache）

### ROB（下一候选）
- **第一步（先于一切探针）**：定义**待估计量**——"ROB 容量"可能有多个可操作定义（在飞指令数 / µOP 数 / 退休率拐点），预注册判据里必须写明本项目估计的是哪一个；
- 真值来源：✗ 无官方真值；第三方实测值仅作**候选区间**（注明各自探针测的是什么量）；
- 协议三要素（缺一不可，评审4-3）：①长延迟锚点（阻止退休的最老指令）②第二可观测量（较年轻指令推进与否的判据）③串行化点位置；
- 混淆清单（D3 重建）：PRF 容量（stuffedcow 明确指出其与 ROB 测量纠缠）、调度器/发射端口、指令融合、**零延迟 MOV（待核查）**、前端取指——结构归因必须靠对照差异而非单曲线拐点；
- 事件：可用 `0x816D STALL_BACKEND_RENAME`（rename full，已核验 TRM p.137）等 stall 事件作**辅助**证据，**禁止**当作"ROB 满"直接计数器；事件语义全部先对照 TRM 第 17 章核验；
- 已确证风险：测量值与 PRF/调度器容量纠缠，"单一变量"极难保证——预注册判据必须写清纠缠假设与对照设计。

### Cache（本仓已有积累，迁移成本最低但 set 构造不可直接继承）
- 真值来源：TRM/DSU-120 手册（容量/相联/替换策略名称）——**注意可配置项 ≠ 目标设备实际配置**（L2 512KB/1MB/2MB 依 SoC 而定，SM8650 具体值须实测确认）；
- 观测面：时延 + 完整 cache 事件族；**地址操纵面须重建**：L1（VIPT）可用 VA 构造（注意 16KB/way 别名边界，机制未公开见开放问题）；L2 及以上为 PIPT，需 /proc/pagemap 物理地址可见性或经验驱逐集；
- 核心方法：继承假设检验框架（C2），prime+probe 为本家技术（D2 修订）；正反对照；
- 混淆清单（D3 重建）：硬件预取器、VIPT 着色、**DSU 他核干扰（替代 v0.1 的"SMT"表述，X4 无 SMT）**、页粒度；
- 与本次 TLB 工作共享：平台清单（A3 有条件项）、B 层纪律、`arm-docs-download`。

### 分支预测器
- 真值来源：**逐子结构查证**（方向预测器容量/间接目标缓存/BTB/返回栈分别查公开资料与优化指南），查不到才降级为"候选区间"模式（C1）；
- 观测面：时延（误预测惩罚）+ BR_* 事件族；**瞬态分析优先**（B3 修订：预测器训练过程本身可能就是测量对象）；
- 核心方法：分支模式构造（C2 重写）；经典方法为模式时延/混叠测量；
- 混淆清单（D3 重建）：前端 resteer、间接目标缓存、取指带宽、**机器码分支布局必须人工核验**（B5 修订）。

## 三、迁移工作流（六步，v0.2 修订第 6 步——评审4）

1. **照搬 A 层**：材料组建（A1/A2）、平台清单（A3 含拓扑确认条件项）、报告骨架（A4）、文书纪律（A5–A7）
2. **定义估计量 + 定真值策略**（C1 修订）：先写清"本探针估计什么量"，再决定走"官方真值校准"还是"第三方候选区间 + 交叉约束"模式
3. **重写 C2 探测原理**：调研该部件的方法谱系（C4），写"构造三要素 → 结构假设 → 验收判据"章；ROB 须含锚点/第二观测量/串行化点
4. **重建 D3 混淆清单 + B6 单变量设计**：评审最容易抓的部分，先写全再动手；含机器码人工核验步骤（B5）
5. **探针骨架**：B3/B5 纪律内置（原始落盘、空窗对照、**瞬态/稳态分分析而非默认剔首轮**、防优化 + **生成码检查**）
6. **放行判据（替换 v0.1 的"评审轮数"门槛——评审4）**：进入目标板采数的唯一依据是**①可观测量协议通过门控 ②混淆控制已实施 ③预注册判据闭环**；评审轮数不作为放行标准
