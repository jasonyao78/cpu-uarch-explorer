# 一级 iTLB/dTLB 分层对照 v1.1

## 本次任务的目的（给人类看）

独立测量一级 instruction/data translation reach，区分一级 refill 与共享二级 walk，裁决匹配 r0p1 资料的 iTLB128/48冲突。官方来源与目标识别分列；不以周期突变单独命名TLB容量。本协议不是旧A1重跑，不改变旧门或旧数据。

## 设计和有限预算

producer `probes/diagnostic/l1_tlb_reach.c`，consumer `tools/diagnostic/l1_tlb_reach_analysis.py`，controller `tools/diagnostic/run_sm8650_l1_tlb_reach.py`。NDK27.2/API34，CPU7，type8，USER-only pinned GROUP+ID/noMUX。i events=[17,8,2,53,1,34]；d=[17,8,5,52,3,1]，事件语义来自官方r0p1 TRM。每mode三fresh epoch，E1反转轨迹和role顺序；固定seed137真实Fisher-Yates。资格N32三fresh完整通过后，才有限scan；先mode d后i，任何技术失败停整个mode，不改参数追门。

d N=[32,64,80,88,92,96,100,104,112,128,160,192]；i N=[32,40,44,48,52,56,64,96,112,120,124,128,132,144,160,192]。同process保持192个memfd backing pages及两个alias（stride5/17pages），每N使用完全相同的PFN/ordinal顺序，两offset形态0/rotating(i&63)*64。所有别名逐page观测pagemap，present/not-swapped/非零唯一PFN且两alias逐一相同；observer不attach。共享file4KiB页映射、guard gaps，实测page-size4KiB，不声明稳态Linux descriptor/hardware coalescing。

d每page两copy next-ordinal，统一6ISA LDR/AND/MADD/ADD/SUBS/BNE，mask0/63；全部N真实走一圈整数闭环，再warm。i每selectedpage单direct B，环末SUBS x0/B.EQ(+8)/B(loophead)/RET，长B避开conditional ±1MiB范围，无indirect per-hop；四role code slot=role*16bytes，同PFN/codepage但bytes/immediate不同，slot是残余BTB差异，不声称完全相同BTB。每N从canonicalRW更新B words，经所有RX别名执行cache同步；运行前后核验实际word。i完整运行retired IR=(N+2)*cycles（末环少一个长B、加一个RET抵消）。direct分支条件控制证实循环次数，不把BR miss零设为先验。

每cell3轮，内含1000000目标hop（实际rounded为完整环），先同数warm；3empty before+12payload(四role×3round)+3empty after，每N18windows。以own FD累计snapshot差计数，不RESET，保留全部empty/payload原值。6events无MUX；d IR/hop=6±.005，i IR/hop=1+2/N±.005；NULL空窗只扣均值，signed不clip。cycles/refill/cache/BR原值全部保留，完整格式以及页/PFN/实际code SHA锚定。

## 预注册判据和停止线

N32资格每mode所有role，所有epoch完整技术/IR；walk/hop≤.001且一级refill/hop≤.01，才scan。scan每curve依epoch×stride×offset成曲线：walk≤.001说明此范围不需明显二级walk；refill/hop≤.01标below，≥.10标above，中间ambiguous。须观测low-side，至少两个连续above，所有N后续不回到below；否则明确left/right-censored/nonmonotone/ambiguous。完整三epoch的共同转折交集才报告范围，不能平均掩盖不同曲线。

若cache refill/hop>.01或BR miss/hop>.01，曲线标记供给残余，仍报告真实translation事件，不能独靠cycles认证一级容量。四role和三epoch的转折不一致，不强报规格128/48/96；若一致且no-walk/IR/cache控制通过，可命名4KiB本协议稳定一级操作reach，并结合规格，不直接认证所有page size/ASID/fully-assoc实现。组织方式和L2 set选择仍需另案。

原始JSONL/data/private、full stdout/stderr/rc，source/build/launch/plan/runtime-pages SHA分列，匿名public summary。producer不改global profile；两个journal面均须终态，pre/post quiet-state原基线，固定进程间15sec。registered mapping/C版本或环境变动另冻结；失败保留，不拼接。未来L2 instruction/data交叉竞争、精确96/128附近更密网格及fully-assoc反例另登记open-items。
