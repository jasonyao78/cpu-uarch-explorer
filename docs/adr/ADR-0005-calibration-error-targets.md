# ADR-0005: gem5 校准误差目标（T1/T2/T3）与"校准/验证"分离铁律

- 状态：已接受（2026-09-23，随需求 v0.3 §9 生效）

## 背景

gem5 O3 对不同指标的建模能力天然不同，统一误差要求要么过严（行为模型达不到）要么过松（结构参数失去约束）。无终止标准会导致调参无穷尽。

## 决策

- 分级目标：
  - T1 必达：指令 latency ±1 cycle；L1/L2/LLC 延迟 ±5~10%。
  - T2 应达：throughput、TLB 容量/延迟、分支 mispredict 率、内存带宽 ±10%。
  - T3 挑战：Geekbench 子项 / SPEC CPU 分 ±10~15%（O3 现实区间）。
- 校准顺序：latency 表 → throughput → cache/TLB → branch → 内存 → 综合分（上层依赖下层）。
- 铁律：microbenchmark 用于校准（允许调参）；Geekbench/SPEC 只用于验证（不许回头调参）。验证集误差代表模型泛化能力。

## 后果

- 校准有明确验收标准与停止条件；误差超阈值时产出"校准差异单"，解释不了的差异进入知识缺口清单（与 `docs/learning/` 联动）。
- D9300 校准启用时机见需求 v0.3 §2.5（M4 Pro 骨架之后）。
